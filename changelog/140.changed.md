pepper now exits like the salt command when no --fail-* option is given: with 1 and an "ERROR: Minions returned with non-zero exit code" message when any minion returns a non-zero retcode or does not respond, with 2 and salt's "No minions matched the target" message when the target matches no minions, and with the job's retcode when a runner or wheel job fails, as salt-run does. Previously it always exited 0. salt-api does not return minion retcodes with --batch, or for the local client with rest_tornado, so in those cases only failed runner and wheel jobs change the exit code.
